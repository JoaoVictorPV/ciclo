# Ciclo das Quintas

Caderno de estudo de piano: ciclo das quintas interativo, todas as escalas por tonalidade, partituras com dedilhado (1, 2 e 3 oitavas e arpejos), variações e inversões de acordes, metrônomo, diário de prática e galeria de prints.

Funciona offline como app (PWA).

## Instalar no iPad
1. Abra o endereço do GitHub Pages deste repositório no **Chrome** (ou Safari).
2. Toque em **Compartilhar** (ícone ⬆︎ na barra de endereço) → **Adicionar à Tela de Início**.
3. Abra pelo ícone uma vez com internet. Depois disso funciona sem internet.

Os dados (progresso, diário, anotações e imagens) ficam guardados no próprio aparelho. Para levar para outro aparelho, use **Ajustes → Exportar / Importar backup**.

## Publicar uma versão nova
Substitua o `index.html` e aumente `VERSION` em `sw.js` (ex.: `ciclo-v2`), para os aparelhos baixarem a atualização.

## Recursos para iPad
- **Tela acesa**: botão ☀ no topo (liga sozinho na sessão de prática e no modo estante).
- **Modo estante**: partitura em tela cheia, com opção de papel claro, para apoiar no piano.
- **Girar o ciclo** arrastando com o dedo ou Apple Pencil.
- **Colar print sem teclado**: toque e segure a caixa violeta e escolha “Colar”.
- **Atalhos** com teclado: ← → (tonalidades), ↑ ↓ (relativa), espaço (tocar/parar), P (partitura), 1/2/3 (oitavas), M (metrônomo), esc.
